# Decision Log

This document records the canonical memory and audit trail for the SLF LLM Wiki product requirements and architecture.

## 2026-05-27
- **Created PRD**: Initial Draft of `prd.md` established using the `bmad-prd` skill, building on the provided `llm-wiki` gist and existing `architecture.md`.
- **Scope Restriction**: Decided to explicitly exclude vector databases, cloud hosting, and automated web searching for MVP to align with the local-first, BM25-based architecture.
- **Knowledge Graph Storage Pivot**: Decided to introduce a knowledge graph to extract entities and relationships from papers and medium articles. To maintain the local-first, lightweight architecture constraint, DuckDB was chosen over a dedicated graph database like Neo4j. DuckDB will act as an embedded relational store for graph nodes and edges.
- **Added Open Questions**: Flagged the need to decide on document chunking vs. large context window reliance, the potential addition of a chronological `log.md`, and how to orchestrate graph queries in the chat interface.
